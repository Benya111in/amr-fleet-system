## 질문

T1 은 같은 seed 면 비트 단위로 같은 결과를 낸다 (결정성 시험). 그러면 "정책 차이로 주장할 수 있는 최소 크기" 는
무엇으로 정하나? Gazebo 에서 실행마다 달라지는 것(통신 지연열, 실행 속도·체류 잡음)만 바꾸고 외생 입력(작업 열,
고장 시각·대상)을 고정했을 때 결과가 얼마나 흔들리는지 — A/A 산포 — 를 잰다. 보고서 186행은 Gazebo 에서 A/A 6 쌍으로
ρ 와 사건열 발산 시각을 먼저 재라고 했다. 여기서는 빠른 계층의 같은 양을 쌍 30 으로 잰다.

## 가설과 예측 (결과를 보기 전에)

- H-AA1: rep 0 대 rep 1 평균 쌍차의 95 % CI 는 모든 (비교군, 셀, 지표)에서 0 을 포함한다. 포함하지 않는 칸이 있으면
  rep 번호가 계통적으로 결과를 바꾸는 것(파생 난수 결함)인지 먼저 의심하고, 15 칸 × 3 비교군 = 45 칸에서 우연히 2–3 칸은
  나올 수 있음(5 %)을 함께 적는다.
- H-AA2: 완료 수의 두 반복 상관 ρ > 0.5 — 작업 열이 결과를 크게 정한다. 서버 충돌(F1)의 A1 은 충돌 뒤 0 이라 ρ 가 더 높다.
- H-AA3: 사건열(할당 순서: 시각·작업·로봇)은 대부분의 쌍에서 300 s 안에 갈린다 — 지연 0–100 ms 와 속도 잡음 ±10 % 로도
  할당 순서가 바뀐다 (보고서 186행: 몇 ms 차이로 사건열이 갈라진다).
- 예측 크기: 제한 평균 지연의 쌍차 SD 5–15 s, 완료 수의 쌍차 SD 1–2 건.

## 설정

- 비교군 A1(현행), A6(완전 분산 CBAA 엄격·투표), A9(제안: 중앙 Hungarian + 투표 + 폴백).
- 셀 (손실, 고장) ∈ {(0.05, F0), (0.2, F0), (0.2, F1)}, 시드 1–30, rep ∈ {0, 1}, λ = 1/45, 지평선 1200 s,
  고장 300 s, `--record` (할당 추적). 540 실행.
- rep 가 바꾸는 것: CommEmulator 루트 시드, 구간 속도 배율 U(0.8, 1.0), 체류 배율 U(0.9, 1.1), 투표 백오프 난수.
  rep 가 바꾸지 않는 것: 작업 도착 시각·도크·물품·우선순위, 고장 시각·대상(F6), 시작 자세.
- rep 0 실행은 본 스윕(P4-4)의 같은 셀 실행과 **digest 가 같아야 한다** (재현성 교차 확인 — 다르면 스윕 사이 비결정성).
- 분석: `python3 -m amr_fleet.fleetsim.report aa` — 지표 completed, latency_rmean, latency_p50, wait_s,
  completed_after_fault 마다 평균 쌍차·95 % CI·쌍차 SD·ρ·MDE(n=30, n=8)·같은 값 쌍 수, 사건열 발산 시각.
- **판정 사용 규칙**: 본 스윕 탐색 표에서 |평균 쌍차| < 같은 지표·셀의 A/A MDE(n=30, 비교군 중 최대) 이면 "A/A 바닥 아래(†)"
  로 표시하고 차이를 주장하지 않는다. MDE(n=8) 는 P5(Gazebo 쌍 8)가 같은 잡음이면 잡을 수 있는 최소 크기의 하한이다

## 해석

- 같은 외생 입력을 공유하는 쌍의 상관이 0.96–0.99 로 매우 높아서 **쌍 30 의 잡음 바닥이 작다**: 완료 수 0.2–0.4 건,
  제한 평균 지연 2–3 s(F0) · 7.6 s(A1 F1). 쌍 8 이면 완료 수 0.5–1.0 건, 지연 4–6 s(F0) · 17 s(A1 F1).
- 이 바닥은 **이 모형의 미시 잡음**(통신 지연열 · 속도 ±10 % · 체류 ±10 %)만 반영한다. Gazebo 의 실행 간 산포는 위치추정·
  제어·실행기 처리 지연 때문에 훨씬 크다 (보고서 208행, SMART 사례 표준편차 0.01 s 대 8.79 s). P5 는 이 표의 MDE8 을
  "최소한 이만큼은 필요" 하한으로만 쓰고, 실제 쌍 수는 Gazebo A/A 6 쌍으로 다시 정해야 한다.
- 사건열 발산이 늦은 쌍이 많다 = 이 모형에서는 작은 통신 차이가 할당 순서를 잘 바꾸지 않는다. Gazebo 보다 결정적이라는
  뜻이고, 쌍비교의 효율(높은 ρ)이 실물보다 낙관적일 수 있다는 경고다.
