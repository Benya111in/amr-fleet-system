## 해석
- r2 의 당시 [계산]: 계약 보상에서 성공으로 끝나지 않는 궤적의 무한 지평 가치는 κ·d₀ − c/(1−γ) = d₀ − 4 로 같고, Φ = −κ·d_arc 가
  대기에 스텝당 (1−γ)κd 를 주어 d > 4 m 에서 시간 비용보다 크다 → 대기 끌개. 리뷰 정정: 이 등식은 **종단하지 않는(절단·부트스트랩)
  궤적에만** 성립한다 (충돌 종단은 −30γ^T 로 다르다).
- 장애물이 없어도(B_noobs1) 정체 1.000 — 장애물 탓이 아니라 보상 구조 탓이라는 근거. 2a(r5)가 v1.1.0 대조(장애물·라그랑주 없음)에서
  끌개가 대기가 아니라 **표류**로 나온다는 것을 보였다 — 끌개의 꼴은 설정마다 다르고(대기·표류·회전), 공통 원인은 "진행이 가치에 안 들어감".
- 비교군 C 를 처음부터 학습한 run 은 2.6M 에서 끊었다 — C 가 순수 탐색으로 되는지는 1차 물결에서 답하지 않았다 (2a 에서 v1.2.0 보상으로
  C 0.937 [측정]).
- 출처 결함: B_main1 은 미커밋 코드("35ce14e+wip")라 정확한 코드를 재현할 수 없다. smoke_B1·B_lag1 은 미커밋 여부 기록이 없다.
