## 해석
- **"PPO 로 성공률 상승" 합격 기준은 미달**이다. B_bc3 의 최종 0.532 는 BC 직후 0.538·시연 휴리스틱 0.535 와 같다 — PPO 는 장애물

- 1차 물결 Isaac(r1)의 정규화 붕괴와 같은 현상을 2D 는 **분산 하한**으로, Isaac 은 **BC 뒤 통계 고정**으로 막았다. 둘 다 "BC 뒤 정규화
  통계가 움직이면 BC actor 가 무너진다"는 같은 교훈이다.
- 학습 중 편향 평가는 0.415 → 0.429 로 보였고 SE 0.022 라 적었다 — 실제 성공률은 0.53–0.54 였다 (다음 항목).
