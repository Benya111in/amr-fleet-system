## 가설과 예측

- 예측: 이식은 C++ 과 **일치**한다. 이산 출력(존, STOP 래치, 원인 집합, 탈출·후퇴·양보 플래그, 명령 낡음)은 정확 일치,
  연속 출력(명령 v·ω, 속도 상한, 거리들)은 |Δ| ≤ 1e-9·max(1, |x|).
- 비트 동일을 기대하지 않는 이유: `std::hypot`·`atan2`·`sin`·`cos` 은 glibc, torch 는 자체(Sleef/CUDA libdevice) 구현이라
  마지막 ulp 가 다를 수 있다. 사칙연산·sqrt 는 IEEE 정확 반올림이라 같은 연산 순서면 비트 동일이다 — 그래서 **경계
  사례는 직진 운동(사칙연산만)으로** 만들어 문턱 바로 위·아래를 비트 단위로 대조한다.
- 버리는 조건: 설명되지 않는 불일치가 하나라도 남으면 이식 결함이다. 무작위 사례에서 이산 불일치가 나면, C++ 이 찍은
  중간값(D·가드 거리 등)이 결정 문턱에서 1e-9 안인지 확인해 "문턱 근접 뒤집힘" 으로만 설명할 수 있다. 같은 종류의
  불일치가 고쳐도 세 번 되풀이되면 재시도를 멈추고 원인을 이 노트에 적는다.

**설정값**: safety_node 가 실제로 쓰는 값 = `config/robot_params.yaml` `safety.*`·`limits.*` +
`src/amr_perception/config/perception.yaml` `safety_node` 블록 (yield_escape.enabled **false**, depth_cloud.enabled
**true** → cloud_required true 등). 이식 모듈의 기본값이 두 설정 파일 원문과 같은지 시험한다 (설정이 바뀌면 깨지게).

**Isaac env 에서의 입력 모델** (교차 시험 대상은 아니고 env 결선의 선택 — README 에 적는다):
- LiDAR: 720 빔, 원형, 원점 base_link (0.15, 0), 매 결정 스텝(10 Hz) 새 스캔, 촬영 시각 = 결정 시작.
- 평가 주기: 50 Hz 서브스텝마다 측정 속도(플랜트 속도) → 명령(프로파일러 출력) → evaluate.
- 깊이 점군: Isaac 에 깊이 카메라가 없다. **"신선하고 비어 있음"** 으로 둔다 (점군이 없으면 cloud_required 때문에
  전진이 0.2 m/s 로 묶인다). 창고 정적 상자 129 개는 모두 LiDAR 평면(지면 +0.20 m)을 지나므로 [측정, 이 노트 결과 절
  명령] LiDAR 가 못 보는 낮은 물체는 없지만, 실제 점군은 같은 면에서 3 번째 최솟값을 내므로 LiDAR 창 통계보다 몇 cm
  일찍 멈출 수 있다 — 남는 차이로 적는다.
- 트랙·TTC: 정적 지도라 없음 (+inf). 도킹 예외: 없음.

**교차 시험 하네스**: `rl/isaac/tools/phi_crosscheck/` — C++ 원본 `safety_gate.cpp`·`geometry2d.cpp` 를 ROS 없이 g++
로 직접 빌드(r0 `rl/contract/tools/crosscheck_cpp.sh` 방식)한 실행기가 이진 입력을 읽어 SafetyGate 를 돌리고, 파이썬이
같은 입력으로 torch 이식(CPU float64, 그리고 CUDA float64 한 번)을 돌려 비교한다. 이미지 `amr-ai/rl:0.3`.

**사례 수 (최소)**:
1. 점별 접근 거리: 무작위 운동 × 점 ≥ 200 000 (직진·원호·제자리 회전·후진·느린 운동·ε 근처·꼬리 있는/없는 경우).
2. 창 통계: 무작위 배열 ≥ 20 000 (빔 수 5–720, 원형·비원형, inf 섞음, 가까운 거리(큰 창)).
3. 순차 evaluate: 무작위 시나리오 ≥ 3 000 (40–60 틱 × 50 Hz, 스캔 10 Hz, 측정·명령 매 틱, 일부 점군·트랙·예외 다각형·
   명령 끊김) + 경계 시나리오 ≥ 1 000 (D = 0.30·0.25·0.50·0.55·1.05 문턱 바로 위아래, 가드 0.02·0.07, 예외 0.10·0.15,
   히스테리시스, 원인별 해제, 탈출 허용·거부, 후퇴, 양보) — 설정 변형 3 종 (배포 설정, yield 켬, cloud_required 끔).

**판정 규칙**: 이산 불일치 0, 연속 위반 0 (또는 원인 규명). **변이 검사**: 이식의 가드·규칙을 하나씩 되돌린 변이
≥ 15 종을 만들어 각각 교차 시험(작은 묶음)을 돌린다 — 모두 잡혀야 한다. 살아남은 변이는 동치인지 원인을 적는다.
