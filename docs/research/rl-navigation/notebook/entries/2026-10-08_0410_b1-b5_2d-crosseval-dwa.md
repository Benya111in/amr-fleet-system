## 가설과 예측 (결과 전에 쓴다 — 위 스모크를 본 뒤다)

- **H1 (P1, 주 결론)**: main_3_15 엄격 성공 Δ = RL(10 시드 평균) − DWA 는 **양수이고 2 원 구간이 0 을 뺀다** (예상 크기 +0.5 – +2 %p).
  근거: 스모크에서 DWA 의 출발 교착·옆 장애물 정체가 넓은 목표에서도 약 1 % 났고 RL 은 Isaac 에서 99.7 %. **기각 조건**: 구간이 0 을
  포함하거나 Δ < 0.
- **H2 (S1, 스트레스 방향)**: stress_3_30 의 Δ 는 양수이고 2 원 구간이 0 을 뺀다 → Gazebo 스트레스(+12.6 [+6.0, +19.6])와 **같은 방향**.
  예상 크기 +20 %p 이상 (DWA 는 좁은 목표 대부분에서 STOP 존 정체, RL 은 Isaac 스트레스 IQM 0.89). **기각**: 구간이 0 포함 또는 음수.
- **H3 (주 방향)**: Gazebo 주 결론은 구간이 0 을 포함했으므로 규칙상 주의 방향 판정은 "방향 판정 불가" 가 된다 (2D 결과와 무관).
  점추정 부호는 Gazebo(−)와 **다를 것**으로 예측한다 (H1).
- **H4 (2D − Isaac, 기술)**: 같은 정책의 2D 엄격 성공은 주 집합에서 Isaac 과 ±1 %p 안, 스트레스에서는 φ 차이(safety_lite 대 정본) 때문에
  더 벌어진다 — 방향은 예측하지 않는다.

- **D5 의 2D 쪽 질문에 대한 답**: 스트레스 집합에서는 2D 도 Gazebo 와 같은 방향(RL 이 높다)이고, 주 집합에서는 Gazebo 쪽이 차이를 보이지 못해

- **스트레스 크기 (+45 %p 대 Gazebo +12.6 %p) 는 2D 가 Gazebo 를 재현한다는 근거가 아니다**: 집합 구성(좁은 목표 비중)과 safety_lite 의 이른 STOP
  [추정] 이 크기를 키운다. 같은 부호라는 것만 말한다.
- 2D 는 같은 정책을 스트레스에서 Isaac 보다 낮게 잰다 (−6.6 %p, 경로 출처와 상관없이 10 시드 모두). 2D 를 RL 정책의 선별 시뮬레이터로 쓰면
