## 질문

정본 safety φ 를 전이 안에 둔 계약 v1.2.0 PPO 에 **개입 비용 제약**(계약 §7.1 보정 크기의 비할인 에피소드 합 J ≤ d)을 PID 라그랑주로
걸면, 예산 d ∈ {0.2, 0.5, 1.0} 마다 (1) 제약을 지키는가 — 평가 개입 ≤ d, (2) 그 대가로 성공률·주행 시간을 얼마나 잃는가 —
같은 env-step 의 무제약 PPO(b1-ppo10 `policy_it160.pt`, 같은 시드) 대비, (3) 승수 λ 가 어떻게 움직이는가?
(완성 계획 B2, 계약 §7.2 "개입·주행시간·성공률 Pareto 와 마지막 λ", 후속 조사 보고서 「제약 RL」.)

## 배경 — 이 설정을 고른 이유 (결과 전)

- **예산 {0.2, 0.5, 1.0}**: 후속 조사 보고서 「제약 RL」 — 계약 §7.2 의 임시 후보 {0.02 … 0.2} 중 0.02–0.1 은 지금까지 잰 실현 가능 정책
  (Isaac BC 0.168)보다 작아 Slater 가 보장되지 않는다. 같은 φ 로 DWA 개입을 잰 값은 아직 없다 (C 단계). → 계약의 "DWA × 1.2" 규칙은 이번에
  쓰지 못한다.
- **무제약 기준 개입** [측정, 다른 실험의 원자료]: A3c 정책의 집합 평가 main_3_15 개입 1.496 /에피소드 중 **성공 에피소드는 0.013** — 평가 개입의
  대부분은 실패(정체) 에피소드 하나당 약 270 이 쌓인 것이다 (`B0_smoke_sets_A3c`, `intervention_share_from_fail`). 그래서 "평가 J ≤ d" 는 사실상
  "주 집합 2 048 중 실패 에피소드 ≤ 약 d·2048/270 개" (d 0.2 → 약 1.5 개, 1.0 → 약 7.6 개) 와 가깝다 [계산]. b1-ppo10 마지막 정책 3–15 무작위
  평가 개입은 시드 0·1·2 에서 1.334·0.153·1.086 [측정, b1-ppo10 원자료].
- **PID 기본값 그대로 쓰면 적분이 포화한다** [측정, `B0_smoke_pid_d0p2`, 노트 `…_2358_b1-binfra_infra-smokes.md`]: 학습 초반 롤아웃 J 가 56–109
  라 정규화 오차 e = (J − d)/d 가 수백 → 적분이 반복 4 에 상한 10, 그 뒤 J < d 여도 e ≥ −1 이라 반복당 0.05 씩만 풀려 40 반복 끝 λ 9.15,
  롤아웃 성공 0.9 %. 예산 0.5·1.0 도 초반 J 보다 훨씬 작아 같은 포화를 겪는다.
- **오프라인 모사** [계산, `analysis/pre/pid_offline.py` — 무제약 롤아웃 J 열(B0_smoke_pid_d200 40 반복 + A3c chunk 개입 41–160)을 PID 에 넣은
  것. 제약이 걸리면 J 가 달라지므로 예측이 아니라 승수 반응의 모양만 본다]:

  | 설정 | d | λ @5 | @10 | @40 | @80 | @160 | λ = 10 인 반복 |
  |---|---|---|---|---|---|---|---|
  | 기본 (자르기 없음) | 0.2 · 0.5 · 1.0 | 10 | 10 | 10 | 10 | 10 · 10 · 9.14 | 157 · 157 · 127 |
  | **e 를 [−1, 1] 로 자름** | 0.2 | 10 | 0.85 | 2.35 | 4.35 | 8.35 | 7 |
  |  | 0.5 | 10 | 0.85 | 2.35 | 4.35 | 6.64 | 4 |
  |  | 1.0 | 7.47 | 0.85 | 2.35 | 4.35 | 5.15 | 0 |
  | 자름 + K_d 0 | 0.2–1.0 | 0.6 | 0.85 | 2.35 | 4.35 | 8.35 / 6.64 / 5.15 | 0 |

  자르면 J ≫ d 인 동안 λ ≈ K_p + K_i·k (k = 반복 수) 로 천천히 오른다. 반복 5 근처의 λ = 10 은 미분항이다 — 미분항 D = max(0, J̄_t − J̄_{t−5})/d 는
  자르지 않으므로 초반 J 가 56 → 109 로 뛸 때 K_d·D 가 수십이 되어 λ 상한에 붙는다 (일시적, 기억 없음).
- **결정**: 바꾸는 것은 **`--pid_err_clip=-1,1` 하나**다 (b1-binfra 가 이 포화 때문에 만든 선택지, 1차 물결 쌍대 상승도 오차를 잘랐다). 이득
  K_p 0.5 · K_i 0.05 · K_d 0.1, λ 상한 10, 미분 지연 5, EMA (0, 0.5) 는 README 기본값 그대로 둔다 — 미분항의 초반 일시 포화는 알고 받아들이고
  λ 궤적에서 따로 센다 (K_d 를 0 으로 바꾸는 것은 두 번째 변경이 되어 하지 않는다). `--constraint_start` 는 쓰지 않는다.
  BC 초기화도 쓰지 않는다 (보고서는 "선택", 무제약 기준선 b1-ppo10 과 제약 말고는 같게 두려고). 보고서의 "보상 쪽 보정 벌점 α ≈ 1" 은
  계약 보상 v1.2.0 을 바꾸는 일이라 이 과제 범위 밖이다 (코드 수정 없음).

## 가설과 예측 (결과 보기 전)

- **H1 (승수)**: 마지막 λ 의 시드 중앙값이 d 0.2 > 0.5 > 1.0 순이다. 예측 범위 (확신 낮음): d 0.2 → 4–10, d 0.5 → 2–8, d 1.0 → 0–6.
  15 run 모두 λ > 0 인 반복이 있다 (반복 5 안). 미분항 때문에 처음 10 반복 안에 λ = 10 인 반복이 d 0.2·0.5 에서 생긴다.
- **H2 (학습 제약)**: 롤아웃 J 의 마지막 10 반복 평균 ≤ d 인 시드 — d 1.0: 3–5/5, d 0.5: 2–5/5, d 0.2: 0–3/5.
- **H3 (평가 제약, 판정)**: 평가 개입(main_3_15, 전 에피소드 평균) ≤ d 인 시드 — d 1.0: 2–4/5, d 0.5: 1–3/5, d 0.2: 0–2/5.
  근거: 평가 개입은 실패 에피소드 수가 정한다 (위 배경). 무제약 it160 의 실패 수를 예산 압력이 얼마나 줄이는지가 관건이다.
- **H4 (성공 대가)**: main_3_15 엄격 성공의 시드 짝 차이(제약 − 무제약 it160) 평균 — d 1.0: −2 … +1 pp, d 0.5: −5 … +1 pp, d 0.2: −20 … 0 pp.
  학습 실패 시드(< 0.90): d 0.2 0–2/5, d 0.5·1.0 0–1/5. λ 가 상한 근처로 가면 "느리게·멈추기" (시간 상한 증가)로 갈 위험이 있다 (B0 스모크).
- **H5 (시간 대가)**: 성공 에피소드 평균 주행 시간 짝 차이 — 0 … +10 %, 작은 d 일수록 크다.
- **H6 (좁은 목표)**: stress_3_15 엄격 성공은 제약 쪽이 무제약보다 0–15 pp 낮다 (장애물 가까이 접근할수록 φ 가 개입하므로 비용이 접근을 막는다).
  확신 낮음.
- **버리는 조건**: H1 의 순서가 뒤집히거나 (d 0.2 의 λ 중앙값 < d 1.0), 15 run 중 λ 가 끝까지 0 인 run 이 있으면 승수가 예산에 반응하지 않는
  것이다 → 집계 전에 진단한다.

## 판정 (결과 전에 고정)

판정 대상은 **마지막 반복** `policy_final.pt` (반복 160). 평가는 `b1_eval_sets_v1.json` 네 집합 (main_3_15·stress_3_15·main_3_30·stress_3_30),

주 결론은 **main_3_15**, stress_3_15 를 같은 표에 나란히, 3–30 m 는 보조.

run 마다 (집합마다 같은 정의로 적되 판정은 main_3_15):
1. **학습 통과** = 엄격 성공 ≥ 0.90 (완성 계획 문턱). 아니면 "학습 실패 시드".
2. **제약 만족 (평가, 판정)** = `layered.intervention_per_ep` ≤ d. 아니면 "제약 위반 시드".
3. 제약 만족 (학습, 보조) = `lagrange_history` 의 J 마지막 10 반복 평균 ≤ d (롤아웃 = DR 켬·확률 행동).
4. **실패 시드 (보고서 정의)** = 엄격 성공 < 0.5 **또는** 평가 개입 > d.
5. 퇴화 = 엄격 성공 < 0.5 이고 시간 상한 + 정체 ≥ 0.5 ("느리게·멈추기"), 또는 제자리 회전 비율 `spin_frac` ≥ 0.5 ("회전 수렴").

예산마다:
- 위 2·1·4·5 의 k/5 와 Wilson 95 % (`amr_rl_eval.binomial`).
- 엄격 성공·Nav2 호환·개입/에피소드·성공 에피소드 평균 주행 시간의 시드별 표, 평균·IQM + 층화 부트스트랩 95 % (`amr_rl_eval.aggregate.stratified_bootstrap`,
  reps 4000, seed 0, 시드 축만 재표본 — 에피소드 표본 오차는 반영하지 않는다). 5 시드의 IQM 은 실패 시드를 잘라 버릴 수 있어 평균·실패 시드 수와
  함께만 쓴다.
- **무제약 대비 대가**: 같은 시드 짝 차이 (PID − ppo10 it160) 의 평균과 시드 부트스트랩 95 % 구간 (reps 4000, seed 0) — 엄격 성공, 개입, 주행 시간.
  구간이 0 을 넘지 않으면 (성공: 위끝 < 0, 시간: 아래끝 > 0) "대가가 있다", 0 을 포함하면 "5 시드로 차이를 말할 수 없다" 로 쓴다.
- λ 궤적: 마지막 λ, 최대 λ, λ = 10 인 반복 수 (처음 10 반복 / 그 뒤 따로), 롤아웃 J 가 처음 ≤ d 인 반복, J 마지막 10 반복 평균.
- **예산 충족 판정** (보고서 「제약 RL」 1 단계 통과 기준을 이 설정에 맞춤): 평가 제약 만족 ≥ 4/5 **그리고** 학습 실패 0/5 **그리고** 성공 짝 차이 평균
  ≥ −2 pp **그리고** 퇴화 0/5 → "충족", 하나라도 어기면 "미달" (어긴 조건을 적는다).

## 해석

1. **이 설정에서 개입 예산은 주로 넓은 목표의 "막힌 실패" 를 겨냥한다.** 무제약 PPO 의 평가 개입은 실패 몇 개 (에피소드당 150 안팎) 가 정하고,
   제약 쪽 실패는 대부분 목표 앞 근접 정지 (개입 ≈ 0) 다 (보충 T8). 그래서 실패 수가 늘어도 (주 3–15 m 29 → 64 · 57 · 44) 평가 J 는 d 아래로
   내려갔고 H3 은 위로 틀렸다. "평가 J ≤ d ≈ 실패 ≤ d·2048/270" 이라는 배경 계산은 실패의 꼴이 바뀌는 것을 빠뜨렸다.
2. **d 1.0 은 걸리지 않는 예산이다.** 무제약이 이미 지키고, λ 는 반복 29–94 뒤 0 — d 1.0 팔은 "초반만 흔든 무제약 PPO" 에 가깝고 그 짝 차
   (스트레스 −4.7 … +7.0 pp) 는 학습 궤적 차이의 크기를 보여 주는 대조군 구실을 한다. 다음 훑기에는 1.0 대신 더 작은 예산이 낫다.
3. **좁은 목표 손실은 방향만 믿을 수 있다.** d 0.2 · 0.5 의 스트레스 짝 차는 대부분 음이지만, 목표 군집·무제약 10 시드로 보면 0 을 포함한다.
   좁은 목표는 φ 개입이 구조적으로 필요한데 (스트레스 개입 > d, 0/5 × 3) 제약은 학습 풀 전체의 기댓값이라 좁은 목표에서 φ 를 덜 부르는
   접근을 배우게 하고, 그 대가가 정밀 정지 실패로 나온다는 가설과 맞는다 [추정, 궤적 미확인]. 스트레스 충돌(시드 2)도 같은 방향의 경고다.
4. **PID 오차 자르기는 효과가 있었다.** 적분 포화가 사라졌고 λ 는 0–3.3 범위에서 반응했다. 다만 끝 λ = 0 이 12/15 라 "마지막 반복" 정책은 대부분
   제약이 꺼진 상태에서 끝났다 — 제약 정책을 쓰려면 λ > 0 구간의 체크포인트나 더 작은 예산이 필요하다.
5. 사전 등록 판정 "세 예산 모두 충족" 은 규칙대로 맞지만, 규칙이 무제약과의 차이를 묻지 않아서 d 1.0 에서는 정보가 없다. 다음 사전 등록에는
   "같은 규칙에서 무제약이 미달인데 제약이 충족" 을 함께 묻는다.
