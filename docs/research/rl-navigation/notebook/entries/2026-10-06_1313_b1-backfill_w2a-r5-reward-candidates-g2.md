- **v1.1.0 → 진행 효용(prog50) 이 순수 PPO 학습 가능성을 바꿨다**: 같은 예산·같은 코드에서 v1.1.0·pbrs_eff 0/3 대 prog50 2/2.

  (`…_1407_…review-seed-failure-knox.md`) — "시드 2 개로 낸 결론이 독립 시드에서 뒤집혔다" 는 노트 README 의 교훈이 이것이다.
- v1.1.0 대조의 실패 꼴은 1차 물결의 "대기" 가 아니라 **표류**였다 (라그랑주·장애물 없음). 끌개의 꼴은 설정마다 다르다.
- κ_b 0.25 는 불안정 (0.198 / 0.000). 0.5 에서 안정적으로 보였다.
- **동적 장애물에서는 prog50 도 실패** (0.000, 1 run) — 2b r6 의 출발점.
- 비교군 C 는 같은 보상으로 처음부터 0.937 — 1차 물결 C_scratch 의 실패도 보상 탓이었을 가능성 (2.6M 에서 끊어 미확인).
