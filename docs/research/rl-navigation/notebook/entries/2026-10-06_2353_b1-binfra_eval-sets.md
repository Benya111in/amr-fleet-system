- **직진 여유** (A3 가 잰 양을 순수 함수로): 경로 끝 접선 자세 = 경로 마지막 점, 방향 = 0.25 m 앞 점(6 번째 앞 점, 간격 0.05 m)
  → 마지막 점. 그 자세의 풋프린트(0.60 × 0.40 m)를 앞으로 곧게 밀 때 정적 사각형(창고 2D 장애물 129 개)에 처음 닿기까지 거리
  (없거나 5 m 초과면 inf, 이미 겹치면 0). = 정본 SafetyGate 의 직진 접근 거리 D 의 기하값.
  구현 `amr_isaac/eval_sets.py::straight_approach_batch` — A3 의 스칼라판 `eval_metrics.straight_approach` 와 무작위 3 000 자세에서
  최대 차 ≤ 1e-12, 실제 창고·합성 경로에서 같은 값 (시험 `tests/test_eval_sets.py`).
- **주 집합** = 직진 여유 ≥ 0.40 m (정지 문턱 0.30 + 0.10), **스트레스 집합** = < 0.40 m. 경계 0.40 은 주 집합 (시험).
- 평가 풀 = held-out 경로 풀 seed 1 (8 192 경로, 내용 해시 `75b8c66b7ede7d38`, 기하 `58eaa34ae5`). 길이 범위 lo ≤ L ≤ hi (env 와 같은 규칙).
- **표본** (seed 20261006):

  - `stress_3_15`, `stress_3_30`: 스트레스 후보 **전부를 고르게 되풀이** (각 경로 ⌊512/K⌋ 또는 ⌈512/K⌉ 번), n = 512
  - `perturb_3_15` = `main_3_15` 의 앞 1 024 개 (교란 묶음의 조건마다 쓰는 주 집합 부분 — 무작위 순서의 앞부분이라 무작위 부분 표본)

- 3–15 m 범위 2 785 경로 중 직진 여유 < 0.30 m 61 개 (2.2 %), < 0.40 m 83 개 (3.0 %) — A3 의 "첫 에피소드 2.3 %" 와 맞는다.

**불리한 것 (집합 설계의 한계)**:
1. **스트레스 집합은 작은 군집이다.** 3–15 m 는 경로 83 개·목표 28 개, 3–30 m 는 경로 244 개·목표 32 개뿐이다. n = 512 는 같은 경로를
   6.2 번(3–15) 되풀이한 것이고 되풀이 사이에는 시작 yaw·LiDAR 잡음만 다르다 — 이항 n = 512 로 잰 구간은 너무 좁다. 그래서 평가 스크립트가
   **목표 군집 부트스트랩 95 % 구간**(같은 목표의 에피소드를 한 덩어리로 복원 추출, `eval_sets.cluster_bootstrap_ci`)을 Wilson 구간과 함께 낸다.
   **스트레스 집합의 주장은 군집 구간으로 한다** (판정 규칙, 아래).
2. 주 집합의 직진 여유 중앙값이 inf 다 — 주 집합 목표의 약 70 % 는 끝 접선 방향 5 m 안에 장애물이 없다. 주 집합은 "쉬운 목표" 쪽으로 기운 표본이
   아니라 풀 자체의 분포(97 %)를 그대로 따른 것이다.
3. 끝 접선 자세는 정책이 실제로 들어가는 자세가 아니다 — A3 리뷰가 보였듯 성공한 좁은 목표는 접선에서 yaw 가 중앙 40–54° 벗어난 자세로 끝난다.
   이 분류는 "직진으로 들어가면 φ 에 막히는가" 의 기하 분류다.

## 판정·보고 규칙 (B 단계 실행자 공통, 결과 전에 고정)

- 정책 하나마다 네 집합을 **따로** 낸다: 엄격 성공 (0.10 m ∧ |v| ≤ 0.05), Nav2 호환 (≤ 0.25 m 비충돌 결정 스텝), 최종 거리 분포
  (중앙·p90·최대, 실패만 따로), 충돌 수, 개입 /에피소드 — `eval.json` 의 `by.<집합>`.
- 구간: 주 집합 = Wilson 95 % (n 2 048), 스트레스 집합 = **목표 군집 부트스트랩 95 %** (Wilson 도 함께 적되 주장은 군집 구간으로).
- 시드 집계 (B1 등): 집합마다 시드별 표 + 실패 시드 비율(성공 < 0.90, Wilson 95 %) + IQM·층화 부트스트랩 (`scripts/aggregate_seeds.py`, `amr_rl_eval`).
- 주 결론은 `main_3_15` (D1 판정) 로, `stress_3_15` 를 같은 표에 나란히 둔다. 3–30 m 는 보조.
