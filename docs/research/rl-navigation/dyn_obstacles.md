- **불리한 것 먼저**:

     0.001·0.057 (2 시드). ③ 라그랑주 + 작은 C 는 5 시드 0.279 / 0.521 / 0.000 / 0.041 / 0.018 — **50 % 를 넘은 시드

     2 048 개에서 장애물을 보지 않는 0.8 m/s 추종기와 결말이 92.5 % 같다 (④ 만 성공 4.9 %, 추종기만 성공 1.9 % —

  3. **G2 실행 규칙을 세 번 어겼다.** (i) ④ 첫 run(bc_s0)은 BC·DAgger 0.74M + critic 예열 0.66M 을 PPO 30M 위에 더해

  무작위·Gazebo 배치 모두에 건다. 위상만 바꾸므로 시작·목표·DR 과 장애물 경로·속력은 그대로다.

## 3. G0 (c) — 회전 끌개의 원인 [측정·계산]

### 3.1 방법

truncate 없는 env 에서 첫 종단(성공·충돌)까지, 길어도 1 000 스텝(100 s, γ^1000 = 0.0067) 할인 보상을 **항별로** 모았다 —
truncation 부트스트랩이 근사하는 무한 지평 가치 V^π(s₀) 의 분해다 (`dyn_diag.continuing_values`). 정적(장애물 없음)·
동적(거르기 없음)·동적(3 s·1.0 m 거르기) 세 env, env 1 024 개, seed 4242. 정책: 대기, 제자리 최대 회전, 추종 0.8/0.3,
PPO 초기 정책 꼴 확률 정책 g(μ_v, μ_ω) — z ~ N(μ, σ = e^−0.5), u = tanh(z) (ActorCriticB 의 초기 log σ). 명령

해석:

1. **동적 장애물에서 "경로를 따라 움직이는 것" 의 값이 대기보다 거의 높지 않다.** 정적에서는 추종이 대기보다 +10.2
   높지만, 동적에서는 +0.6 이다 — 진행 효용·목표 (+5.5) 를 충돌 항(−8.9 대 대기 −2.0)이 거의 다 먹는다. 추종기보다
   서투른 정책(느린 추종기 0.3 m/s 는 −3.3)은 대기보다 낮다. 학습 초기의 정책은 0.8 m/s 추종기보다 서투르므로, 그
   정책에게는 대기가 낫다 — 「이론」 199행의 정지 유인(조우 위험 p 가 p\* ≈ 32 % 보다 크면 정지)과 같은 현상이다.
2. **충돌 사건이 수익 분산의 76–94 % 를 차지한다** (정적은 0). PPO 는 보상을 할인 수익 표준편차로 나누고 advantage 를
   배치마다 정규화하므로, 진행 효용(1 m/s 에서 스텝당 +0.05)의 신호는 −30 충돌 사건의 분산에 묻힌다.
3. **회전 자체는 대기보다 값이 높지 않다** (−0.08, 3.8 % 시나리오에서만 우연히 피해 높다). 보상은 ω 를 보지 않는다 —
   회전은 시작 한 번의 평활 비용(−0.019)만큼 낮다. 그런데 **잡음 있는 정책에게는 회전 쪽으로 기우는 것이 이득이다**:
   g(0, +0.5) 는 g(0, 0) 보다 +3.4 높다 (정적 +3.2) — 무작위 걸음이 경로에서 표류하며 받는 추종·힌지 벌점(−3.9)이 ω 를
   한쪽으로 기울이면 −1.8 로 준다. μ_v 를 내리는 쪽(g(−0.3, 0) 0.40 > g(+0.3, 0) −4.55)도 같은 이유다. 그래서 정책이
   전진을 포기한 뒤 μ_ω 가 한쪽으로 쏠려 결정론적 평가에서 제자리 회전(84 %)으로 보인다. 회전 끌개 = "대기 끌개 + ω 의
   무의미한 쏠림" 이다.
4. **개입 비용은 학습 신호가 아니다**: 보상에 없고, 계약 §7.2 예산이 미정(None)이라 라그랑주에서도 λ = 0 이다. 무작위
   정책의 에피소드 개입 합은 154–611 로 크지만 학습에 영향이 없다. 회전의 개입 합은 0.65, 대기 0.
5. 처방: (i) 충돌 신호를 학습 초기에 줄이기 — C 를 낮추고(③) 또는 쉬운 단계부터(①) — C = 10 이면 느린 추종기도 대기보다
   +1.2 높다 (뒤집히는 C ≈ 15); (ii) 충돌을 행동 단계에서 막기(② VO 마스크); (iii) 학습을 움직이는 정책에서 시작하기
   (④ BC).

## 7. 왜 안 되는가와 다음 시도

1. **학습 초기 신호** (§3): 동적 장애물에서는 "움직이기" 의 값이 대기보다 거의 높지 않고 충돌 사건이 분산을 지배한다.
   ③ 은 C 를 10 으로 낮춰 움직이기를 살렸지만(5 시드 모두 진행 0.5–0.7), 예산 d = 0.10 을 지키지 못해 λ 가 상한까지
   올라 실효 C 가 30 으로 돌아가고, 시드 대부분이 직전 정지로 끝났다. 다음: (a) λ 상한을 실효 C ≈ 15 (§3.2 의 뒤집힘
   지점)로 두거나 d 를 처음엔 크게 두고 줄이는 예산 일정, (b) 시드 선별 대신 실패 원인(직전 정지)을 직접 — 2a §6 의
   목표 근처 성공 조건 커리큘럼.
