  PPO 도 스트레스 집합에서 it160 대 최종이 크게 섞인다 (b_ppo10 §6).
- **평가 조건**: Isaac 안 정적 창고 지도 하나, 정본 φ, DR 끔(명목값), 결정론 tanh(μ), env 마다 첫 에피소드. 주 집합 n 2 048 은 서로 다른 목표 501 개라

- **벽시계**: 공유 GPU (Isaac 슬롯을 다른 B 단계 과제와 공유, loadavg 7–49) 위의 예비값. SAC·PPO 의 부하가 달라 벽시계 비교는 판정하지 않는다.
