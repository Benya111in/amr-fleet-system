## 0. 목적과 정직성 선언

1. 기존 논문(feature/dwa-ablation `474264e`)의 결론을 **새 경로 집합(held-out B)** 에서 재현하고, 논문 한계 두 가지를 측정으로 메운다.
   - stateful 판정
   - 잡음 기제
2. 기존 결과에서 원인이 드러난 약점을 고친 **연구 변형 DWA-R** 을 만들고, Nav2 비교군과 **같은 튜닝 예산·같은 선택 규칙**으로 공정하게 비교한다.
3. DWA 의 설계 목적(장애물 회피)이 드러나는 **정적 미지 장애물 장면**을 더한다.

**정직성**
- DWA-R 의 설계는 held-out A 결과(`results.md` §1·§6)를 보고 정했다. 그래서 held-out A 는 더 이상 평가에 쓰지 않는다.
- 확증 판정은 새 시드로 만든 held-out B 에서만 한다.
- 기존 알고리즘 코드(`src/amr_navigation/**` 등)는 **수정하지 않는다**. 연구 변형은 새 패키지 `src/amr_nav_research/` 의 사본 코드다.
- 사본의 연구 스위치를 모두 끄면 원본과 비트 단위로 같아야 한다 (§3.3 동치 시험).

## 2. 연구 스위치 (DWA-R 후보, 기본값 = 끔 = 원본과 동일)

| 스위치 | 내용 | 기본 |
|---|---|---|
| R1 `reset_persist_cycles` K | 명령–측정 차가 임계(0.3 m/s, 0.5 rad/s)를 **K 주기 연속** 넘을 때만 창을 측정값으로 되돌린다. 차가 `reset_hard_v`(0.6 m/s)를 넘으면 즉시 되돌린다(막힘·와인드업 방지) | K = 0 (원본 동작) |
| R2 `jerk_consistent` | 방출 명령의 가속 변화를 하류 프로파일러 저크 한계(2 m/s³)로 묶는다. 창 = [v_last + (a_last − jΔt)Δt, v_last + (a_last + jΔt)Δt] ∩ 가속 한계. 최대 감속(제동) 후보는 예외 | 끔 |
| R3 `pp_candidate` | 순수 추종 곡률 후보 (v*, ω = v*·κ_pp) 를 샘플에 더한다. κ_pp 는 배포 방향 항과 같은 lookahead(clip(0.4v+0.3, 0.4, 1.2) m)로 계산하고, 창으로 자른 뒤 같은 비용으로 평가한다 | 끔 |
| R4 `approach_latency` t_c | 기존 파라미터 값만 바꾼다 | 0.30 s |

## 3. 시험대·경로·팔

### 3.2 경로 집합
- **튜닝 집합:** 기존 4 경로 그대로.
- **held-out B (새로 만듦):** `make_paths.py` 와 `plan_astar.py` 를 사본으로 쓰고 **시드만 20261018** 로 바꾼다. 분포는 held-out A 와 같다: 매끈 32, 좁은 통로 8, 창고 A* 20.
- **정적 장애물 장면 O (새로 만듦, 20 장면):**
  - held-out B 매끈 경로 가운데 앞 20 개를 쓴다.
  - 경로 호길이 30–70 % 구간에, 지도에 없는 원판(반지름 U(0.25, 0.40) m) 1 개를 경로 위 ±0.1 m 에 놓는다.
  - 원판 바깥으로 로봇이 지날 여유(≥ 0.8 m)가 없는 배치는 다시 뽑는다.
  - kinematic_sim 의 기존 `moving_obstacles` 파라미터에 속도 0 으로 준다.
  - **공정성:** DWA 팔은 추적 장애물 토픽(참값)을 쓰지 않고 코스트맵(LiDAR)만 쓴다. Nav2 팔과 같은 정보다.

## 6. 지표와 통계 (기존과 같음)
- **지표:** 성공, T/T_ref, log 시간비 짝 차, CTE 직선·곡선 평균/최대, 정지 오차(부호·절대), 제어기 출력 저크 p99, 0→0.9 m/s 시간, 좁은 통로 최소 여유, 계산 시간.

- **통계:** 표본 단위 = 경로(seed 는 경로 안에서 먼저 평균). 구간은 경로 묶음 부트스트랩 B = 10 000, seed 12345, 백분위 95 %.

### 6.1 확증 가설 (셋, 각각 단독 판정)

- **H1r (재현):** chain_sim 사슬 20 Hz, held-out B, 잡음 없음, stateful false 에서 M3 를 끄면 주행 시간이 늘어난다.
  - 통계량: 두 팔 모두 성공한 경로의 mean log(T_no_m3/T_full).
  - 판정: 95 % 하한 > 0.
- **H2 (잡음 강건성):** ROS C3 에서 DWA-R 이 dwa_full 보다 빠르다.
  - 통계량: 12 경로의 seed 평균 log(T_R/T_full) 의 평균.
  - 판정: 95 % 상한 < 0.
- **H3 (시간 비열등):** ROS C1 에서 DWA-R 이 RPP 기본보다 0.5 % 넘게 느리지 않다.
  - 통계량: 두 팔 모두 성공한 경로의 mean log(T_R/T_RPP).
  - 판정: 95 % 상한 < log(1.005).

나머지는 모두 **기술(구간)** 로만 보고한다.
- 정지 정확도 순위, CTE, 저크, stateful true 효과, O 장면 성공률은 판정하지 않는다.
- **우위 주장은 확증 가설과 구간이 0 을 벗어난 짝 비교에서만** 한다.
