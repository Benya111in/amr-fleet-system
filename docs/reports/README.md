## 로그 포맷

명세 표에 정의된 형식을 따른다.

```
위치 추정 : [timestamp, gt_x, gt_y, est_x, est_y, error]
경로 추종 : [timestamp, planned_x/y, actual_x/y, cte]
응답 시간 : [cmd_time, response_time, latency_ms]
```

로그는 `logs/` 에 저장하고, 분석 스크립트는 `scripts/` 에 둔다.
